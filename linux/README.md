# Overview

This section contains the backup for the linux - archlinux environment. The window manager used is Wayland-based **niri**. We use **waybar** as the status bar. The terminal used is **Alacritty**. **SDDM** ( Simple Desktop Display Manager is a light-weight opensource graphical login program & session manager for linux that support X11 and wayland. We are using the same for display manager.

- niri - window manager
- waybar - statusbar 
- Alacritty - terminal
- SDDM - display manager
